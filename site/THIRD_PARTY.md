# Third-party assets

The site self-hosts three variable fonts. Only the latin subset, weight-axis
files are copied into `site/fonts/`. Each font is licensed under the SIL Open
Font License, Version 1.1.

| Font | File in `site/fonts/` | Version | Licence | Copyright |
|---|---|---|---|---|
| Bricolage Grotesque (variable, `wght`) | `bricolage-grotesque-latin-wght.woff2` | 5.3.0 | SIL OFL 1.1 | Copyright 2022 The Bricolage Grotesque Project Authors (https://github.com/ateliertriay/bricolage) |
| Geist (variable, `wght`) | `geist-latin-wght.woff2` | 5.3.0 | SIL OFL 1.1 | Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font) |
| Geist Mono (variable, `wght`) | `geist-mono-latin-wght.woff2` | 5.3.0 | SIL OFL 1.1 | Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font) |

The files were taken from the `@fontsource-variable/bricolage-grotesque`,
`@fontsource-variable/geist` and `@fontsource-variable/geist-mono` packages.
